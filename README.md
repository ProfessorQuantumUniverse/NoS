### Voting- & Programm-App für die Night of Science.

Eine Web-App für die *Night of Science*: Besucher:innen können über Vorträge abstimmen, das Programm durchstöbern und Live-Ergebnisse verfolgen.

## ✨ Features

- 🗳️ Live-Voting für Vorträge
- 📊 Echtzeit-Ergebnisse
- 📖 Digitales Programmheft
- ⏱️ Warte- & Konfliktauflösungs-Ansichten
- 🔧 Eigenes Backend mit `events.json`

## 🛠️ Tech-Stack

`JavaScript` · `HTML5` · `CSS3` · `Node.js (Backend)`
